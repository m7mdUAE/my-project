# PlateBookingWeb — ASP.NET Web Forms (C#)

Open the solution file `../OPEN_PLATE_BOOKING.sln` in Visual Studio 2022.
All three views (bookings, management, dashboard) are within `PlateBooking.aspx`.
The project starts in safe localhost-only, read-only preview mode; see `../START_HERE.md` for setup and switching to Windows-authenticated live mode.
The real SQL Server connection name is `PlateBookingDB`, configured in `Web.config`.
No NuGet packages are required and no fake customers/bookings are generated.
